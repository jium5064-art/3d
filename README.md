# C++ 3D Physics Engine

## 🌐 웹에서 실행

[▶ 3D 물리엔진 실행](https://jium5064-art.github.io/3d/)

### 웹 조작
- **WASD** 이동
- **SPACE** 점프
- **마우스** 시점 조작

## 기능

- C++ 3D 물리 엔진
- 웹 3D 플레이어 데모
- WASD 이동
- 마우스 시점 조작
- 중력
- 점프
- 바닥 충돌
- 아레나 경계 충돌
- 가속 / 감속
- 3D 테스트 오브젝트

## C++ 빌드

- C++17 이상
- CMake 3.20+
- raylib 5.0+

```bash
cmake -S . -B build
cmake --build build
```
